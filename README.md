# PIANO LIBRARY 루트 사이트

`thddnlwhd-cpu.github.io`의 루트에서 기존 피아노 악보방(`/piano_library/`)으로 이동시키고, AdSense 확인 코드와 루트 `ads.txt`를 제공합니다. 이 파일들은 이름이 정확히 `thddnlwhd-cpu.github.io`인 GitHub 공개 저장소의 기본 브랜치 루트에 배포해야 합니다. 프로젝트 저장소 `piano_library` 안에 넣으면 `/piano_library/ads.txt`에 배포되어 도메인 루트의 `ads.txt`를 대신하지 못합니다.

GitHub Pages를 기본 브랜치의 루트(`/`)에서 게시한 뒤 `https://thddnlwhd-cpu.github.io/ads.txt`가 텍스트 한 줄을 반환하고 `https://thddnlwhd-cpu.github.io/`가 기존 사이트로 이동하는지 확인합니다. 그다음 AdSense에서 소유권 확인과 검토 요청을 진행합니다. `ads.txt`가 표시되어도 AdSense 상태 업데이트에는 시간이 걸릴 수 있습니다.
